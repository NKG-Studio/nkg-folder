# NKG Virtual Folder

面向多项目、多分支开发的 Windows 文件工作区。Rust 原生桌面程序，默认四分屏、深色扁平界面、紧凑树列表。

右上角可切换 VS Code 深色、Catppuccin Mocha、Nord 和浅色四套主题。导航、窗口及文件类型图标统一为矢量线条；Segoe UI 与微软雅黑字体配合紧凑的 22px 列表行。

## 启动

Release 程序是 `artifacts/nkg-virtual-folder.exe`（单文件可执行程序）。关闭旧版后运行新版。EXE 使用 `asInvoker` 清单，主窗口保持普通权限，支持与 Windows 资源管理器双向拖拽。正常双击启动后，通过 UAC 为后台文件访问申请管理员权限；窗口自身不提权。后台负责受保护目录的枚举、路径解析、属性读取、应用内文件操作及搜索。拒绝 UAC 时仍可按普通权限使用，底部显示权限状态。拖入虚拟区仅添加引用；拖入真实目录默认复制，按 Shift 移动。手动以管理员身份运行时，普通资源管理器的拖放仍会被 Windows 权限隔离阻止，可使用应用内选择器。常规构建产物位于 `target/release/nkg-virtual-folder.exe`；也可在项目目录执行：

```powershell
cargo run --release
```

开发环境为 Rust 1.97.1 / Windows x64 MSVC。构建需要 Rust 和 Visual Studio C++ Build Tools；运行已构建的 EXE 不需要 Rust、Node.js、WebView 或 Unity。

应用图标保留橙色 NK 图案，并在右下角加入 VF 标识，源图保存在 `assets/app-icon-master.png`。`assets/app.ico` 包含 16–256 像素的多尺寸图标，由 `build.rs` 嵌入 EXE；`assets/app-icon.png` 用于窗口、任务栏及自绘标题栏。图标已嵌入程序，分发时无需附带 assets 目录。

## 日常使用

- **新建工作区**：顶部面板加号创建未绑定路径的空面板，显示拖入文件或文件夹的提示。拖入目录后直接浏览真实目录；拖入文件后浏览其所在目录并选中文件。多个路径分别打开标签页，不复制或移动文件，也不创建虚拟节点。

- **排序**：各面板右上角排序图标菜单提供类型、名称、修改日期，各面板独立选择并保存设置；旧版全局排序自动迁移到各面板。文件夹始终在前；类型按扩展名分组，名称不区分大小写升序，修改日期最新优先、未知日期在后。目录树在每层内部排序，虚拟引用使用实际文件日期；搜索结果完成后排序。虚拟文件的多个映射取最近修改日期，纯虚拟文件夹没有修改日期。

- **虚拟文件夹**：虚拟面板导航栏的“文件夹＋”图标创建，可嵌套。将真实目录或文件拖到虚拟节点上，只建立引用，不移动真实文件。已有虚拟文件、虚拟文件夹和引用可拖入其他虚拟文件夹重新组织；阻止拖入自身或后代。右键也可通过原生选择器添加路径。
- **虚拟文件**：虚拟面板导航栏的“文件＋”图标创建，再拖入不同分支的文件。双击后列出全部映射，分别支持“打开文件”“所在目录”“移除映射”。拒绝目录映射，重复路径自动去重。
- **多面板**：默认四分屏。顶部“新增工作区面板”图标按钮新增标签；拖动标签可分屏、重新停靠、调整分组或浮动。没有固定面板数量上限，实际容量受屏幕与内存限制。关闭全部面板后，用顶部“新增工作区面板”图标按钮恢复。
- **目录树**：点击箭头按需展开，双击目录进入，地址栏可直接输入绝对路径。路径与导航按钮同一行。支持 Ctrl / Shift 多选。
- **框选**：从列表空白处或文件名右侧按住鼠标左键拖动，框选经过的行；Ctrl / Shift 框选追加到已有选择，Esc 取消本次框选，靠近列表上下边缘自动滚动。拖动文件名仍执行原有文件拖放。
- **选中项详情**：各面板底部单行显示选中项名称、大小和本地时间的修改日期，替代总条数、选中条数和粘贴 / 添加按钮。多选显示已选项数、所选文件总大小和最近修改时间；文件夹不递归统计大小，虚拟项没有对应实体时显示“—”。信息后台读取，选择稳定后加载并定时更新；粘贴仍可使用 Ctrl+V 或右键菜单。
- **路径显示**：地址栏、映射、提示和复制完整路径统一使用 `/`，隐藏 Windows 的 `\\?\` 前缀；网络路径显示为 `//server/share`。加载旧工作区时自动更新地址栏格式。底层文件操作保留原始路径，兼容 Windows 长路径。
- **递归搜索**：搜索框默认收起，点击各面板右上角放大镜展开并自动聚焦，再次点击收起（保留查询与结果）。输入名称片段，停止输入 300 毫秒后自动递归搜索，Enter 立即搜索；清空搜索框返回列表。在当前真实目录下递归查找；虚拟目录则搜索其全部引用路径，重复路径去重。后台流式返回，支持停止与返回列表；右键结果可打开所在目录。
- **全电脑搜索**：顶部原刷新位置改为放大镜按钮，打开居中的模态搜索窗口，自动聚焦输入框。按文件名或路径搜索，忽略大小写，空格分隔的关键词同时匹配；支持双击 / Enter 打开、上下键选择、在面板中定位、右键复制路径，Esc 或点击遮罩关闭。F5 仍刷新原有面板。
- **本地搜索索引**：不依赖 Everything，启动后后台预热本地固定磁盘和可移动磁盘。SSD 可在同卷内并行枚举，全局最多 4 路；机械盘或设备能力未知时同卷顺序处理。直接从各磁盘根目录开始扫描，不先全盘预读 MFT；各卷独立队列轮转调度，扫描与索引构建之间保留 8 批有界缓冲。扫描中可查询已完成部分。查询使用不可变分块快照、三字节子串倒排、公共路径/后缀跳过和完整候选缓存；缓存最多 32 个查询、候选存储预算 64 MiB，连续输入可缩小候选，索引变更后按版本失效。输入当帧提交，取消旧查询；先显示前 500 项，再由常驻工作线程补全准确总数，“总数统计中”表示当前计数尚未完成。界面耗时只包含查询和结果生成，不包含键入到显示的完整延迟；列表仅绘制可见行。文件变更只替换受影响索引块，查询与磁盘缓存写入不持有索引锁。
- **索引同步与缓存**：Windows 原生监听只订阅文件/目录名称变化；系统通知溢出、异常通知和应用队列溢出会触发重新核对。可写实例将带版本及 CRC 校验的目录表、文件名和倒排块原子保存到配置目录的 `file-index.bin`，最多每 30 秒保存一次；旧 `file-index.json` 可读取迁移，损坏或不兼容的缓存会重建。缓存不含文件内容，后台核对期间结果可能过期。首次扫描使用目录枚举；具备卷访问权限时，使用与快照绑定的 USN 检查点恢复变更。目录项仍由枚举取得，保留硬链接的全部名称；日志不连续、卷身份变化或无法可靠解析时回退核对。管理员后台的提权需经 UAC 授权；程序不创建或修改 USN 日志。不跟随目录联接/符号链接，不搜索网络盘；无法枚举的位置会提示。模态窗口可手动重建，关闭搜索保留索引；新接入磁盘需重启应用。
- **复制路径**：真实文件、虚拟引用及侧栏节点的右键菜单提供“复制路径”，复制实际路径文本，统一使用 `/`；多选或多个映射时每行一条并去重。
- **系统右键菜单**：右键真实文件、目录或路径引用，选择“Windows 系统右键菜单…”，调用 Windows 原生菜单及已安装扩展。支持多选，仅在主动打开菜单时加载扩展。
- **跨面板拖拽**：真实文件拖到另一个真实目录面板默认复制，按住 Shift 移动（Ctrl 优先复制）；拖到文件夹行则放入该子目录。目标高亮并显示操作及路径，同名文件不覆盖。拖到虚拟目录仍只添加引用。
- **真实文件操作**：右键打开、复制、剪切、重命名、新建文件 / 文件夹、移入回收站、永久删除。新建图标统一位于各面板的上一层按钮旁。永久删除菜单和确认按钮标红，通过后台 PowerShell 命令调用 .NET 文件删除，不经过回收站；拒绝根目录和直接选择的符号链接 / 目录联接，遇到只读文件或目录联接可能部分失败并报告错误。粘贴重名时停止，不静默覆盖。删除前显示真实路径确认框。
- **虚拟节点移除**：右键移除或在虚拟行上按 Delete，只移除引用。展开真实目录后，其子项是实际文件，删除会出现回收站确认框。

## 数据与性能

主题选择、虚拟节点、文件映射、面板布局、目录与展开状态保存到当前用户的 `AppData/Local/NkgFolder/workspace.json`。每两秒检查变化并保存，退出时也保存；临时文件写入完成后替换原配置。第二个实例只读配置，避免相互覆盖。配置损坏时会明确报错并禁用保存，原文件保留。

配置通过 Windows 的 `SHGetKnownFolderPath(FOLDERID_LocalAppData)` 获取，固定使用当前用户的 `AppData/Local/NkgFolder/workspace.json`，不写死用户名，不读取环境变量，不回退到临时目录，不自动导入 EXE 旁的恢复文件。工作区自动保存，帮助中可查看配置位置。目录或配置不可访问时明确报错并禁用保存。手动恢复仍会先校验备份并保留原配置。

主窗口采用深色自绘标题栏：拖动标题或顶部空白处移动窗口，双击最大化 / 还原，边缘可调整大小；右上角提供最小化、最大化和关闭。

文件复制使用 Windows 标准 `CF_HDROP` 与 `Preferred DropEffect` 剪贴板格式；移动完成后只清理未被用户改动的剪贴板。参见 [Microsoft Shell 剪贴板格式](https://learn.microsoft.com/zh-cn/windows/win32/shell/clipboard)。

目录读取与排序运行在两个后台线程，文件操作另开后台线程。目录仅在访问 / 展开时扫描；文件列表仅绘制视口中的行。缓存由面板共享，F5 清空并重新加载。未集成 SVN/Git 状态、缩略图、文件内容预览或 Shell 图标扩展；图标由程序绘制。

依赖使用 [eframe/egui](https://docs.rs/eframe/0.35.0/eframe/) 和 [egui_dock](https://docs.rs/egui_dock/0.20.1/egui_dock/) 提供原生渲染及停靠，不自建窗口布局框架。

## 当前边界

这是首个可运行版本，尚未完整覆盖 Windows 资源管理器的全部功能。

- 支持与资源管理器互相复制 / 剪切 / 粘贴真实文件。文件拖出窗口时交给 Windows 原生拖放，目标程序决定复制或移动（Ctrl 复制、Shift 移动）；拖入真实目录默认复制，Shift 移动，拖入虚拟节点只添加引用。仅接收实际磁盘文件路径，不接收邮件附件等虚拟文件内容。
- 移动支持同盘和跨盘，目标存在时不覆盖。同盘直接重命名；跨盘逐项调用 Windows 原生文件移动，并且只移除已搬空的源目录。复制使用 `CopyFileW` 保留文件属性和备用数据流；复制及跨盘移动暂拒绝符号链接 / 目录联接，目录 ACL 与时间戳不保证完整保留。
- 批量复制失败会报告已完成项和失败目标；可能保留部分目标内容，源文件不会因此删除。没有取消 / 撤销队列。文件操作中关闭窗口会被阻止，等待操作结束即可关闭。
- 虚拟引用绑定路径。真实文件被重命名、移动或删除后不会自动改写引用；可在映射选择器重新添加。失效路径在打开时报告错误。
- 面板搜索结果在应用内文件操作结束（包括部分失败）、系统菜单返回、虚拟引用变更和 F5 后重新搜索，并清空旧选择。外部新增、删除、改名和权限变化通过 Windows 目录通知检测：连续事件合并 300 毫秒（最长等待 2 秒），当前扫描完成后重搜；扫描期间的变化也会触发补扫。停止搜索会停止外部监听，F5 可恢复。普通目录列表的外部变化仍需 F5。网络文件系统可能不返回通知；监听建立失败会提示手动刷新。
- 面板搜索默认递归，按文件名、不区分大小写，不读取文件内容、不使用全盘索引、不递归进入目录联接或符号链接。单次最多显示 100,000 个结果，达到上限会明确提示缩小范围；无法访问的路径显示跳过数量和首个错误。目录缓存保留至 F5 / 退出。
- 搜索命中时后台记录卷号、文件 ID、创建 / 修改时间和大小；应用内删除、重命名、移动前核验目标，身份无法读取、文件被替换或修改时取消操作并提示刷新。删除 / 重命名确认框保留打开时的身份，本程序剪切后的粘贴保留剪切时的身份。校验与实际路径操作之间仍存在并发变化窗口，不是文件系统事务；交给系统菜单、外部拖放或其他应用的操作由 Windows / 目标应用执行，不能保证其后续行为。
- 未实现压缩包浏览、独立权限编辑及网络凭据管理；这些不属于当前验收范围。系统菜单提供的命令交由 Windows 执行。

## 验证

在项目目录的 PowerShell 中运行：

```powershell
cargo fmt --check
cargo test -- --nocapture
cargo clippy --all-targets -- -D warnings
cargo build --release
```

34 项测试覆盖三种排序、目录层级保持、搜索与虚拟引用排序、排序设置保存及旧配置兼容，以及框选、Ctrl 追加选择、滚动后框选、Esc 恢复选择、文件大小与日期读取，以及搜索结果在实际删除、外部新增 / 改名 / 删除及操作失败后刷新、手动重搜清空选择、同名替换后拒绝删除 / 回收 / 重命名 / 移动，以及永久删除的路径隔离与特殊字符处理、默认应用失效时的打开方式回退、工作区恢复备份与失败保护、默认递归搜索触发、路径格式与旧地址迁移、虚拟映射去重与类型限制、删除引用不影响真实文件、虚拟节点重组与循环拒绝、含初始未绘制面板的布局保存 / 恢复、复制防覆盖与子目录拒绝、真实文件创建 / 重命名、原生跨盘移动与 NTFS 备用流保留、文件剪贴板 UTF-16 编码与移动标志检查、四面板拖拽及外部投放事件传递、递归搜索与错误反馈、跨目录多选的真实 Windows 菜单生成和十万条缓存目录项的可见行渲染。跨盘测试在系统临时目录与当前工程所在盘之间创建临时样本，会打印是否实际跨盘。

十万条测试使用合成缓存，不读取真实磁盘，不等同于磁盘 I/O 基准。`cargo test -- --nocapture` 会打印当前机器上的列表构建与稳定帧耗时。原生窗口已启动检查中文显示、四分屏、目录浏览与虚拟节点创建；外部拖入与原生跨面板拖拽尚需进一步实机验收。

文件打开通过 Windows Shell 文件关联直接调用默认应用，不经过 PowerShell。如果文件存在但默认应用缺失或关联失效，弹出系统“打开方式”供用户选择应用；不自动修改默认关联。外部拖入时通过系统鼠标坐标定位目标面板，窗口内外拖放已获用户实机确认。

图标使用矢量线条绘制，不依赖特殊 Unicode 字形。

面板列表空白区域右键可在 Windows 文件管理器中打开当前目录；虚拟面板提供实际目录选择，重复目录合并，无映射时禁用此项。

左侧拖入区域每次接收文件或文件夹时，按首项名称创建独立虚拟工作区，同名自动加序号；拖到已有分组则追加引用。

侧栏上方约 80% 为虚拟工作区，独立滚动并固定底部拖入入口，边框为缓慢流动的彩色细线；磁盘与位置在底部竖排，箭头展开按需加载的目录树，点击名称打开面板。拖动两区域间的分隔条可调整比例。边框采用连续插值渐变，仅在窗口获得焦点时连续刷新。

虚拟工作区顶部搜索框按分组和引用名称筛选（不区分大小写），保留匹配节点的祖先，清空后恢复原展开状态；彩色边框带渐变衰减光晕。

虚拟节点可拖到左侧工作区列表空白处或底部拖入框移回顶层，也可使用右键“移回工作区顶层”。

后台使用仅本机可用的命名管道，核验父子进程身份、可执行文件和提权状态，随主程序退出。通信断开时不会自动重试文件操作；缓存使用原用户权限读写。文件路径以原生 UTF-16 传输，保留特殊名称。拖出文件使用 Windows 标准文件拖放格式，不暂存、不主动删除源文件；是否允许目标位置的复制或移动由资源管理器判断，必要时 Windows 仍可能要求确认。

权限不会自动传给外部编辑器或系统右键菜单。程序不自动修改 ACL、获取所有权或解密文件，管理员也无法保证访问所有路径。

cargo test --release backend::tests::elevated_round_trip -- --ignored --nocapture
